# Política de Privacidade — BrunexFI

**Última atualização:** 16 de abril de 2026

## Coleta de dados

A extensão BrunexFI **não coleta, armazena nem transmite** nenhum dado pessoal do usuário.

## Armazenamento local

A única informação armazenada é a preferência de porcentagem de substituição de imagens, salva localmente no navegador através da API `chrome.storage.sync`. Esse dado é usado exclusivamente para manter a configuração do usuário entre sessões.

## Compartilhamento de dados

Nenhum dado é compartilhado com terceiros, servidores externos ou qualquer outro serviço.

## Permissões

- **storage**: para salvar a preferência de porcentagem do usuário.
- **host_permissions (todas as URLs)**: para injetar o script que substitui imagens nas páginas visitadas.
